# Revenge Plugins
Plugins for Revenge / ShiggyCord / Vendetta by realm_wth.

---

## How to install?
Paste a plugin URL into the Plugins page of Revenge / ShiggyCord:

```
https://realmwth.github.io/Revenge-Plugins/PLUGIN_NAME
```

### Plugins:
- **ValidUser-NG**: `https://realmwth.github.io/Revenge-Plugins/ValidUser-NG`
